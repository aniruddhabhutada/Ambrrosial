# Ambrrosial Essence — Luxury Fragrance House & Digital Atelier

> **Composed in India · Small Batch Extrait de Parfum & Curated Olfactory Accords**  
> Inspired by high-end artisanal fragrance houses, featuring warm linen palettes (#eeebe6 / #f4f1eb), terracotta bronze accents (#9e4318), and refined typography.

---

## Overview

**Ambrrosial Essence** is an editorial e-commerce and consultation experience crafted for personal distinction. The website showcases six signature flacons composed with rare botanicals, wild saffron, velvety Taif rose, and aged Assam oud wood.

### Key Highlights
- **Studio-Quality Commercial Imagery:** Photorealistic perfume flacons composed on travertine limestone, polished black marble, and morning desert atmospheres.
- **Editorial Typography:** High-contrast pairing of *Host Grotesk*, *Cormorant Garamond*, *Cinzel*, and *IBM Plex Mono*.
- **The Notes in Three Movements:** Staged olfactory storytelling illustrating top, heart, and base evaporation pyramids over time.
- **Interactive Accord Matcher:** Personalized scent discovery by fragrance families (*Warm & Sensual*, *Modern Floral*, *Lustrous Fruity*, *Sweet & Gourmand*, *Refined Woody*).
- **Direct WhatsApp Concierge:** Seamless one-tap consultation and bespoke inquiry generation.
- **Fully Responsive Mobile View:** Tailored mobile layout with touch-friendly pills, edge-to-edge scrolling, and solid mobile menu drawer.

## Getting Started

### Prerequisites
- Node.js (v18 or higher recommended)
- npm or pnpm

### Installation

`ash
# Clone the repository
git clone https://github.com/aniruddhabhutada/Ambrrosial.git

# Navigate to the project directory
cd Ambrrosial

# Install dependencies
npm install

# Start local development server
npm run dev
`

Visit http://localhost:5173/ in your browser.

### Production Build

`ash
# Build optimized production bundle
npm run build

# Preview production build locally
npm run preview
`
